Privacy Policy

Last updated: 2026-09-11

Zim Job Bot is a personal automation tool built and used by a single individual (its owner) to help with their own job search. It is not distributed, offered as a service, or used by anyone other than its owner.

What it accesses

The bot uses the Gmail API with the https://www.googleapis.com/auth/gmail.send scope only - this permission lets it send email as the owner's own Gmail account. It cannot read, search, or delete anything in that mailbox; that scope is not requested.

What it does with that access

The owner's own credentials are used only to send job-application emails (CV, cover letter, and a short message) that the owner has personally reviewed and approved, to job postings the owner has chosen to apply to. No data is shared with, or sold to, any third party.

Data storage

Job listings, match results, and drafted application text are stored in a private database (Upstash Redis) accessible only to the owner, to track what has already been reviewed or applied to. No data collected from this tool is used for advertising or shared with anyone besides the owner.

Contact

Questions about this tool can be directed to the contact email on its GitHub repository.
